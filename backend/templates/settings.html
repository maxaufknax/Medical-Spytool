About MedicalSpy

MedicalSpy Version 3.0 is a web-based scientific publication search tool for medical and scientific research.

This application allows you to search across multiple databases including PubMed and the Deutsche Nationalbibliothek (DNB), analyze results, and export data in various formats.

Features:
  • Multi-database scientific publication search
  • Advanced search options with date ranges and filters
  • Person management for associating searches
  • Result visualization and analysis
  • Export to CSV and Excel formats
  • Detailed logging and error tracking
Technology:
  • Backend: Flask (Python)
  • Frontend: Bootstrap, JavaScript, Chart.js
  • Data Processing: Pandas, XML parsing
  • APIs: PubMed E-utilities, DNB SRU
