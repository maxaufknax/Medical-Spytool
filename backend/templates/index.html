So funktioniert's

1. Suche

Gehen Sie zur Suchseite:

  • Datenbank wählen
  • Suchbegriffe eingeben
  • Filter anwenden

2. Ergebnisse

Die Ergebnisseite zeigt:

  • Gefundene Publikationen
  • Filter & Sortierung
  • Export-Optionen

3. Analyse

Auf der Analyse-Seite:

  • Trends erkennen
  • Daten visualisieren
  • Analysen exportieren
Erste Schritte

Beginnen Sie, indem Sie zur Suchseite gehen:

  • Geben Sie Schlüsselwörter oder Suchbegriffe ein
  • Wählen Sie eine Datenbank (PubMed oder Deutsche Nationalbibliothek)
  • Verwenden Sie erweiterte Optionen für Datumsbereiche und zusätzliche Filter
  • Ordnen Sie Suchen bestimmten Personen zu, um die Organisation zu verbessern

Nachdem Ihre Suche abgeschlossen ist, werden Sie zur Ergebnisseite weitergeleitet:

  • Durchsuchen Sie Ihre Suchergebnisse im Tabellen- oder Kartenformat
  • Filtern Sie die Ergebnisse mit dem Suchfeld
  • Sortieren nach verschiedenen Spalten
  • Exportieren Sie die Ergebnisse als CSV- oder Excel-Datei zur externen Analyse

Besuchen Sie die Analyse-Seite, um Ihre Ergebnisse zu visualisieren:

  • Veröffentlichen Sie die Verteilung nach Jahr
  • Sehen Sie die Hauptautoren in Ihren Ergebnissen
  • Vergleichen Sie die Verteilungen der Datenbanken
  • Analysieren Sie Zitationsmuster
