# Schnellstartanleitung für Medical Spytool

## Anwendung starten

1. **Windows-Benutzer:**
   - Doppelklicken Sie auf die Datei `Start-MedicalSpytool.bat`
   - Die Anwendung wird automatisch gestartet und im Browser geöffnet.

2. **PowerShell-Benutzer:**
   - Öffnen Sie eine PowerShell
   - Navigieren Sie zum Verzeichnis: `cd c:\Users\paaschma\Documents\coding\medical_spytool_6.2\Medical-Spytool-2`
   - Führen Sie aus: `powershell -ExecutionPolicy Bypass -File .\Start-MedicalSpytool-Improved.ps1`

## Anwendung verwenden

1. **Suche starten:**
   - Gehen Sie zur "Schnellsuche"-Seite
   - Wählen Sie mindestens eine Datenbank aus (PubMed, Deutsche Nationalbibliothek)
   - Geben Sie einen Suchbegriff ein
   - Klicken Sie auf "Suchen"

2. **Bei Problemen:**
   - Stellen Sie sicher, dass mindestens eine Datenbank ausgewählt ist
   - Überprüfen Sie die Internetverbindung
   - Starten Sie die Anwendung neu mit der `Start-MedicalSpytool.bat`
